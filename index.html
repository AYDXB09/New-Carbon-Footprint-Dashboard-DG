    Calculation Methodology

    Monte Carlo Simulation

    This tool performs 10,000 iterations (configurable) to account for uncertainty in emission factors. Each iteration samples from the specified distributions to calculate total emissions.

    Distribution Types

    • Log-normal: Used for device power consumption to model right-skewed real-world usage patterns
    • Uniform: Used for emission factors where only min/max bounds are known from literature

    Calculation Steps

    1. Parse CSV data and validate against outlier thresholds
    2. For each Monte Carlo iteration:
      • Sample device power from log-normal distribution
      • Sample emission factors from uniform distributions
      • Calculate emissions for each row × factor × regional grid intensity
      • Sum all emissions for this iteration
    3. Calculate percentiles from all iterations
    4. Generate confidence intervals and visualizations
